# 🎠 Carousel Maker

Веб-приложение для генерации каруселей (наборов слайдов с текстом на фоновых изображениях) для Instagram, VK, WhatsApp и Telegram.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Скачивание шрифтов Inter (опционально)

Для лучшего рендеринга скачайте шрифты Inter и положите их в `static/fonts/`:
- `Inter-Regular.ttf`
- `Inter-Medium.ttf`
- `Inter-Bold.ttf`

Если шрифты не найдены, будет использован системный шрифт по умолчанию.

### 3. Запуск

```bash
python app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

## ✨ Функционал

### Главная страница
- Ввод темы карусели
- Выбор количества слайдов (1–10)
- Создание проекта с автоматической генерацией заглушек текста

### Редактор проекта (3-колоночный интерфейс)

**Левая панель — миниатюры слайдов:**
- Список всех слайдов с превью
- Перемещение вверх/вниз
- Дублирование
- Удаление (кроме последнего)
- Переключение светлой/тёмной темы
- Добавление нового слайда

**Центральная область — превью:**
- Мгновенное обновление при изменении параметров
- Фиксированный размер превью (масштаб 40% от выходного)

**Правая панель — настройки:**

| Категория | Параметры |
|-----------|-----------|
| **Текст** | Заголовок, подзаголовок, основной текст, цвет, позиция |
| **Шрифт** | Размеры (20–170px), межстрочный интервал, межбуквенный интервал, отступ абзаца |
| **Фон** | Загрузка изображения, прозрачность, градиент (цвет, позиция, прозрачность, глубина) |
| **Темы** | 12 предустановленных цветовых схем (Ocean, Sunset, Forest, Berry, Monochrome, Coral, Mint, Lavender, Gold, Rose, Teal, Slate) |
| **Проект** | Соотношение сторон (4:5, 1:1, 9:16), номера слайдов, водяной знак |

### Экспорт
- Скачивание ZIP-архива со всеми слайдами в формате PNG
- Разрешение: 1080×1350 (4:5), 1080×1080 (1:1), 1080×1920 (9:16)
